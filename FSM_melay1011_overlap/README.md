### DUT and SystemVerilog Testbench for Mealy 1011 Overlapping Sequence Detector with Functional Coverage
In this project, I designed a Mealy Finite State Machine (FSM) to detect an overlapping 1011 sequence with an asynchronous reset. I also developed a complete, layered SystemVerilog testbench architecture that includes an automated Scoreboard, Functional Coverage, and interface Assertions.

## Features
- Mealy FSM 1011 overlapping sequence detection
- Asynchronous reset and positive edge-triggered clock
- Layered Object-Oriented SystemVerilog testbench (Generator, Driver, Monitor, Scoreboard, Environment)
- Functional coverage to verify reset toggles and specific sequence hits
- Assertion-based verification using SystemVerilog Assertions (SVA)

## Tools Used
- EDA Playground (Aldec Riviera-PRO)
